# 检索复跑 · 主张 F（同域对照 vs 跨域：增益反映损失函数而非域差）

- 日期：2026-10-04
- 通道入口：`scripts/90_fetch_via_jump.py`（口令只走 `JUMP_PW` 环境变量，未落盘）
- 被检主张：同域对照（17 格，5x 学习率策略，均值 +0.27 pp，中位 +0.65，29% 负，16/17 达 |t|>=2）
  与跨域（130 格，均值 +1.10 pp，中位 +0.94，23% 负）两组**不配对**，故"增益来自损失函数而非域差"只能是定性比较。
- 对照面（contrast face）：把迁移增益解释为**域差/域对齐效应**的工作；以及任何做过**同域 vs 跨域微调增益对比**的工作。
- 结论一句话：**未找到**任何把增益明确归因于"损失函数而非域差"的先例；但"表观迁移增益其实来自训练/优化侧而非迁移本身"这条**去魅路线**已有多篇成熟工作，其中一篇（Li 等 2021）已在**目标检测**上直接做过"同域（目标集）预训练 vs 跨域（ImageNet）预训练"的对比并报同域更优。

## 4. 最接近的一篇 + 判词

**最接近：Li Yang, Zhang Hong, Zhang Yu, "Rethinking Training from Scratch for Object Detection", arXiv:2106.03112 (2021)。**

判词（3–8 句）：

1. 这是本轮唯一在**目标检测**上直接做"同域预训练 vs 跨域预训练"比较并给出量化增益差的工作：用目标数据集（COCO）自身做"direct pre-training"，与 ImageNet 跨域预训练对照。
2. 它的结论方向与主张 F 的**经验事实**一致而更激进：目标域自预训练不仅不差，反而 "while with even +1.8mAP compared to ImageNet pre-training" ——即同域对照可以**超过**跨域，而不是"也有正增益"。
3. 因此它威胁的是**该对比的新颖性**（新颖度层）：审稿人完全可以说"检测器的同域 vs 跨域预训练对比早就做过，而且同域还赢"。
4. 但它**不威胁**主张 F 的**归因**：Li 等讨论的是"分辨率/BN/训练阶段"这类工程机制，从未把增益归因于**损失函数**，也未做"域差是否存在"的消解论证。
5. 它也**不威胁**主张 F 的**统计形态**：没有 17/130 格、没有均值 pp、没有 |t|>=2 的逐格检验，也没有"两组不配对只能定性比较"这一自我限定。
6. 真正在**去魅归因层**集体施压的是第 2–5 条（He 2019 / Raghu 2019 / Kanavati 2021 / Pototzky 2022）：它们分别把表观迁移增益归给**收敛加速**、**过参数化与权重缩放**、**BN 仿射参数**、**更精细的训练协议**。
7. 这四篇合起来意味着："增益其实不来自迁移/域差"**不是一个新论点**；主张 F 若要立住，新意只能落在**把归因具体钉在损失函数上**，以及**同域对照组本身的实测分布**（17 格、29% 负、16/17 达 |t|>=2）。
8. 而这一具体归因（"损失函数"）在本轮所有通道与措辞下**未找到先例**——注意是"未找到"，不是"不存在"。

## 5. 证据强度声明

- **可达通道数**：5 条探测目标全部 HTTP 200（Crossref、DataCite、arXiv 落地页、arXiv export API、OpenAlex）。实质承担检索的是 3 条：**Crossref、OpenAlex、arXiv**。
- **降级情况（逐项）**：
  1. **arXiv export API 在并发下被限流**：手工布尔式 4 连 429 / 1 byte（含 20 s 后重试仍 429），**记为取数失败**；改用脚本 `arxiv` 模式后 10 条检索式全部 200 且含真实 entry。故 arXiv 证据链完整，但有"布尔 AND 型检索式缺失"这一缺口。
  2. **Crossref 记录结构性无摘要**：3 条 DOI 直取均 `NO_ABSTRACT`，属数据源特性而非通道故障；已用 OpenAlex 倒排索引补齐 5 条。
  3. **OpenAlex 关键词模式排序很松**（C1–C3 大量不相关），已降级为**次要通道**，实质结论基于字段限定式 D1–D21。
  4. **1 条候选摘要不可得**（Otović 2022），四路尝试均失败，已在候选表中如实标注"摘要不可得"，未凭记忆补写。
  5. arXiv 落地页在 `url` 模式下按 20000 字节截断，故 arXiv HTML 搜索页（`arxiv.org/search/`）只解析出 2 条标题——该路已弃用，不作为证据。
- **结论的正确表述**：本报告的一切"没有/未出现"均应读作 **"在这些通道与这些措辞下未找到"（not found under these channels and these phrasings）**，**不是** "不存在（does not exist）"。特别是：
  - "增益来自**损失函数**而非域差"这一具体归因 ⇒ **未找到先例**。
  - "同域 vs 跨域检测预训练对比" ⇒ **已找到**（Li 2021；另有 RadImageNet、Breaking the ImageNet Pretraining Paradigm、Otović 2022 三条不同任务上的同类对比）。
  - "表观迁移增益并非迁移本身所致" ⇒ **已找到多篇**（He 2019、Raghu 2019、Kanavati 2021、Pototzky 2022）。

## 6. 阴性对照记录

用 `probe` 内建的**确定不存在的词** `zzqxwvuytnonexistentterm`：

| 对照 | URL 目标 | HTTP | 字节数 | 返回内容 |
|---|---|---|---|---|
| NEG-crosref | Crossref `query.bibliographic=zzqxwvuytnonexistentterm` | 200 | **187** | `items` 为空（无任何候选） |
| NEG-arxiv | arXiv export API `all:zzqxwvuytnonexistentterm` | 200 | **728** | 0 个 `<entry>` |

**判读（区分"零命中"与"取数失败"）**：
- 真实检索式的量级：Crossref 真检索 15556–73588 B，OpenAlex 真检索 1451–7817 B，arXiv 有命中 17320–19675 B。
- arXiv **合法的零命中**为 768–812 B（A1–A4），与阴性对照 728 B 同量级；而**限流失败**为 **1 B + HTTP 429**，与上述两者在字节数与状态码上均可区分。
- 故本通道**能区分**三种状态：零命中（~700–800 B / 200）、有命中（>1400 B / 200）、取数失败（1 B / 429）。阴性对照证明通道不会对不存在的词返回伪命中。
