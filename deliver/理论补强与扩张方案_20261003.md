## 三、五个扩张选项（按"性价比 × 可证伪性"排序）

### ★ 选项 A（**首推**）：把 measurement-hierarchy proposition 形式化

| 项 | 内容 |
|---|---|
| **要立的命题** | 定义两类量：**轨迹求值的一阶读**（worst-direction 增量、梯度范数、对齐余弦）与**驻点求值的二阶读**（谱、曲率）。命题：**前者是轨迹状态、不是端点结局的驻点预测器**——沿轨迹求值的一阶量，其与端点泛化间隙的关联**不具跨预算的稳定性** |
| **从哪推** | 补材 **L4**（二阶展开）+ **L5**（flatness–谱关系）+ **L7**（曲率迁移）；假设足迹用 **H1/H8**（H3 不用） |
| **底座里可算的证据** | §6 的 **18/18 格 SNR<2**（事前冻结的门）就是该命题的经验对应物 ✅ 已在稿内且**有守卫** |
| **证伪条件** | 找**任一格**其一阶读的 SNR ≥ 门限且跨预算符号稳定 ⇒ 命题在该格失效（**这正是可报告的**） |
| **页数** | **+2.0 页**（1 页命题与假设、0.5 页证明梗概、0.5 页与 §6 数值的对应） |
| **风险** | **中**——证明必须自洽；但**装置已存在**（补材 A 的引理），主要是**搬运 + 与新节号对接**，不是新数学 |

### ★ 选项 B（**首推**）：**可探测性理论**——成对预算干预的可分辨性

| 项 | 内容 |
|---|---|
| **要立的结论** | 给定成对设计（$n$ 个配对种子、逐种子差值的种子间 SD $\sigma$），**最小可探测差** ${\rm MDE}=t_{1-\alpha/2,n-1}\cdot\sigma/\sqrt n$（配对口径）；由此给出**设计规则**：要在 $1-\beta$ 功效下分辨大小为 $\delta$ 的符号翻转，需要 $n\ge(\,(t_{1-\alpha/2}+t_{1-\beta})\sigma/\delta\,)^2$。**并给出 $(\delta,n)$ 功效表**，说明"**小于 X pp 的翻转在 $n\le10$ 下不可分辨**" |
| **从哪推** | 补材 **F** 已有的零假设越界推导（$n=3$、$q$ 表）+ 稿内既有的 **0.31 pp @ 80% 口径**（SD 0.308 pp，$n=10$） |
| **底座里可算的证据** | 逐格种子间 SD（底座已按 `(配对,族,预算,轮数,臂)` 分组）⇒ **可对每个格算 MDE**，做成一张"哪些格的结论在功效之下"的表 ✅ **不需要新数据** |
| **证伪条件** | 若某格报出的符号差异**小于该格自己的 MDE**，则该格不应被当作证据——**我们可以主动跑这张表，把不合格的格自己挑出来** |
| **页数** | **+2.0 页**（0.5 页推导、1 页功效表、0.5 页用法与 §5 预注册判据的对接） |
| **风险** | **低**——标准统计，正确应用即可；且**它让 §5 的"判据未达标"从一次事件变成一套方法** |

### ★ 选项 C（**首推**）：**预算响应的两项模型**——把"headroom"从说法变成可证伪的条件

| 项 | 内容 |
|---|---|
| **要立的模型** | $\Delta(B)=U(B)-M(B)$：$U(B)$ 是**优化路径随预算带来的可用余量**（随 $B$ **递减**，因为预算越大、可改进空间越小），$M(B)$ 是**预算引起的失配代价**（随 $B$ **递增**，更大预算＝更长优化＝更易过拟合目标子集）。⇒ 符号翻转的**充要条件**是 $U'(B)-M'(B)$ 过零 |
| **可推出的可检验含义** | ①**翻转只发生在 $B$ 足够大处**（与 `visdrone→dota15` 在 100→200ep 由 +3.727 落到 +2.584 一致）；②**亚饱和目标域更容易翻转**（余量大⇒更早耗尽的不是 $U$ 而是 $M$ 起主导）；③**同域对照的 $M$ 更小** ⇒ 同域格更不易翻转（§4.6 的 +0.27 vs +1.10 同向） |
| **从哪推** | 补材 **J** 的逐项对应（`The source-side residual — the only term the experiment tests directly`）+ J.0 的 `The direction of the coupling` |
| **底座里可算的证据** | 逐格符号与预算的**排序**（85% vs 25%、17/20 vs 6/8）✅ 已有守卫；**但** $U$ 与 $M$ 的**分离不可得**（§8 自陈与 §二约束 2 一致） |
| **证伪条件** | 若某格在**大预算**下增益**上升**且不是在 $U$ 未耗尽区，模型在该格失效 ⇒ **要写成"未分离、故为候选机制"** |
| **页数** | **+2.5 页**（1 页模型与条件、1 页三条可检验含义、0.5 页明确写"未分离"的边界） |
| **风险** | **中高**——价值最大（把描述变成预测），但**必须**把"未分离"写在显眼处，否则等于宣称做过分离实验 |

### 选项 D（**建议次轮**）：**两轴不对称**的形式化

* **现象**：轮数轴 **17/20 负**，而标签轴 **6/8 正**（§4.5，有守卫）。
* **要立的说法**：把两轴视作两个**预算泛函**；给出**何时一个轴是"饱和型"、何时是"探索型"**的判据（如：当基线增益已接近目标域的可行上界时，增量预算只能造成失配）。
* **证据**：底座的分组统计 ✅（不需新数据）。
* **页数**：**+1.5 页**；**风险低**（是解释而非新数学）。

### 选项 E（**建议缓做/或明写不做**）：把**联合界**（补材 J）提上正文

* **能做**：Corollary 1 + Proposition 1 上正文，配逐项对应与 H1–H10 的假设足迹。
* **代价与风险**：**+3 页**；**假设 10 条**；而且**它自己的经验读数是 $r=+0.004$** ⇒ 审稿人会问"为什么要放一个不预测的界"。
* **唯一合适的放法**：**明写为"负结果的框架"**——界的用处不是预测，而是**把四个项各自的责任范围钉死，从而说明为什么本次实验只能检验其中一项**。若这么写，**+1.5 页**即可（只留陈述与足迹，推导留补材）。
* ⇒ **建议**：**等 A/B/C 落定后再定**；若要放，按上述"负结果框架"写法，**不要**按"理论支撑"写法。

## 五、**明确不做**的（三条约束的直接推论）

1. **不碰 selection premium**（姊妹论文的地盘）——补材 E.2/E.4 已划界。
2. **不宣称架构轴/损失轴/密度因果**——`03_榨干报告` §三明确"需要新数据"；现有稿把它们写成"候选/边界"是**正确的**，扩张理论**不得**把它们升格为结论。
3. **不把联合界当已验证预测器**——其经验读数是 $r=+0.004$，只能作"负结果框架"。

## 六、落地的第一步（可直接执行）

**先做 B**，因为它**不需要新数据、风险最低、且立刻能出表**：

```
输入：底座按 (配对, 族, 预算, 轮数, 臂) 分组的逐种子差值
输出：① 每格的种子间 SD σ̂ 与 n；② 每格的 MDE(α=0.05, 80%)；
      ③ 一张"符号差异 vs 该格 MDE"的表 ⇒ 标出**哪些格的结论在功效之下**
判据：若某格 |Δ| < MDE ⇒ 该格的符号不得作为证据（应写明"功效不足"）
验证：与 §4.2 既有口径（SD 0.308 pp、MDE 0.306 pp、n=10）**必须对上**
```
> 这张表**本身就是可投稿的内容**，而且它与本稿"审计"的体裁完全一致——
> **用功效去审自己的结论**，是这篇稿子最自然的理论增量。
