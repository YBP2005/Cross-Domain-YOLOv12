# 选项 B 的结果：**全档案功效审计**（2026-10-03）

## 一、方法（与稿内既有口径一致）

配对设计下，`n` 个配对种子、逐种子差值的种子间 SD 为 `sigma_hat`：

    MDE(n, sigma_hat) = ( t(1-alpha/2, n-1) + t(power, n-1) ) * sigma_hat / sqrt(n)
    alpha = 0.05,  power = 0.80

**判据**：`|Delta| < MDE` ⇒ 该格的符号**在 80% 功效下不可分辨**，不得作为符号证据。

**★ 一致性校验（必过）**：`n=10, sigma_hat=0.3080` ⇒ MDE `= 0.3064`，
与稿内 §4.2 的 **0.306 pp / SD 0.308 pp** 口径**对上** ✅

## 二、总结果

| 项 | 值 |
|---|---|
| 可算 MDE 的格 | **147** |
| 其中 `|Delta| < MDE`（功效不足） | **43（29%）** |
| **n = 3 的格** | **73 个，其中功效不足 32 个（44%）** |
| **n > 3 的格** | **74 个，其中功效不足 11 个（15%）** |

⇒ **功效不足几乎全部来自 n=3 的格**（44% vs 15%）——这为稿内"三方划分／十种子／预注册"的设计选择
提供了**定量理由**，而不只是"我们做得更严"。
