## 结论

1. **8 条 ❌未复现里，6 条已被"族混杂"解释掉**（`smoke` 100/50/200ep、`shwd2sf` 四点、
   YOLO11n 100ep）—— **不是论文写错，是复算口径把不同 run 族混成了一格**。
   旧口径 `06_A25.py: cells()` 的格键是 `(pair, epochs)`，**没带 `family`**。
2. **唯一真正的取件缺口**是 `smoke→sfchd` 30ep 少的那个种子的 **test 读数**：
   底座里**确实有 s50**（`b2_smoke2sf_{base30,lr005_30ep}_s50n.incomplete_20260924_104028`），
   它**跑满 30/30** 但被存档为中断件、**未写 test 行**。可核算式：
   `9 种子 test 均值 +3.5511`（sum 31.960）→ 要得 `10 种子 +3.656`（sum 36.560）
   ⇒ 第 10 个种子须 **+4.600**；其 val 侧实测 **+4.593** ✓ 相符。
   ⇒ **闭合动作 = 补跑这 2 个 run 的 test 评测**（只评测不训练）。
3. **YOLO11n 两点各差 0.012 / 0.015 pp，方向一致** ⇒ 该组最可能是"同批 run 的一次略不同的评测"，
   **结论（30ep 有增益、100ep 无增益）站得住**；投稿时要么写明是哪三个种子（`s42,s43,s44`），
   要么交代这 0.01 pp 的来源。
4. **§4.3 的 `mask→mendeley` 是唯一还没闭合的一条**：论文 n=5、p=0.016 与 df=4 ⇒ t≈−4.02 自洽，
   但族 `t2`（n=5）给 −0.902（4/5）、族 `r10`（n=13）给 −1.170（11/13）。
   签名搜索在 `r10` 上命中一组 5/5 全负且 t 逐位相符的子集 ⇒ **最可能出自 `r10`（clean 三方协议）**。
   ⇒ **请作者确认 §4.3 用的是不是 `r10_p_masktomende_*_3way`，以及是哪 5 个种子。**
