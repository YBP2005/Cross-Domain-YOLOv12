# 预注册草案：**固定图数、只变标注密度**（G2）— 2026-10-04

> **状态：草案，未冻结**。本件是继 `预注册_新目标域复制实验_冻结_20260913.md`（T1/T2）与
> `预注册草案_预算×域差2x2分离设计_20261004.md`（G1）之后**第三个**预注册件。
>
> **它为什么存在（缘由，先于结果）**：G1 已经把预算与域差分开，但**暴露了一个新的共变**——
> **同一对的 10% 与 50% 两档，训练图像数同时从 141 变到 705（5 倍）**。
> ⇒ G1 测到的是"**标注预算 × 训练图像量**"的合成，**答不了"预算是否设定符号"**。
> 本件的**唯一目的**：**把图数钉死，只动标注密度**，使"标注量"成为唯一在变的因子。

---

## 1 要回答的问题（冻结）

**Q**：**在训练图像集固定的前提下**，改变**每张图被标注的实例比例**，
"策略增益的符号/幅度"是否随之改变？

**不在问什么**（先写清，防事后挪靶）：

| | |
|---|---|
| **是** | **标注密度**单独对增益的效应（图集固定） |
| **不是** | 图数与标注量的交互（那需要**两维都动**的设计，本件不做） |
| **不是** | 跨语料的推广（本件只在**一个同语料对**上做，见 §2） |

**H1（主假设，冻结）**：在**固定图集**上，把标注密度从 **10% 提到 50%**，
策略增益的**符号**发生改变；即"标注密度 × 密度档"的简单效应显著。

**H2（次级，冻结）**：增益**随标注密度单调**（10% < 25% < 50% 的单调性），
若单调成立则报单调，若不成立则如实报"非单调"（**不追曲线**）。

**不检验**：跨语料推广、理论界、几何读数、模块类干预。

---

## 2 设计：单因子三档，图集**完全固定**（冻结）

**固定的是什么（这是本件的全部要点）**

| 项 | 值 |
|---|---|
| **训练图像集** | ★ **固定为 `dota15` 的 705 张**（＝G1 的 c2 用的那个集合，`train/50_percent/images`） |
| 域对 | ★ **固定为一个同语料对**（`dota15 → dota15`）；**只用同语料**，理由见下 |
| 目标 / 评估集 | `dota15` 的 `images/val`（458 张，与 G1 同口径） |
| 管线 | 与 G1/T1 完全同栈（YOLOv12n、SGD、batch 32、imgsz 640、100 轮、`--shuffle-seed 42..51`） |
| 两臂 | `shapeiou @ lr0.001`（基线）与 `shapeiou @ lr0.005`（策略） |

**动的只有一个因子：标注密度（三档）**

| 档 | 每张图保留的实例比例 | 做法 |
|---|---|---|
| `d10` | **10%** | 对每张图的实例**确定性随机抽 10%**（种子固定，写下抽样脚本与种子） |
| `d25` | **25%** | 同上 |
| `d50` | **50%** | 同上 |

**run 数（冻结）**：3 档 × 2 臂 × 10 种子 = **60 run**。

**为什么只用同语料对**：G1 显示**符号反转只出现在同语料对上**。
若在跨语料对上做，**先验上就不预期反转**，那么"没反转"是**预期结果、无信息量**；
在**同语料对**做，才是**检验那个已观察到的反转是否由标注量驱动**。

**为什么三档而不是两档**：G1 的两点设计**只能判"符号是否改变"**；
本件加一个中间档，**能判单调性**（H2），且中间档若与两端同向，可直接暴露"非单调"。

## 3 协议（与 G1 同栈，冻结）

| 项 | 取值 |
|---|---|
| 模型/优化 | YOLOv12n（COCO 起步）；SGD momentum 0.925、wd 1e-4、warmup 3；batch 32、imgsz 640、AMP off、**workers 16**（与 `train_obj.py` 硬编码一致） |
| 两段式 | 阶段 1 复用既有 `dota15_pretrain.pt`（**不重训**）；阶段 2 = 705 张固定图、**100 轮** |
| 种子 | `--shuffle-seed 42..51`（十枚），两臂**同种子配对**；框架 `seed` 固定 42 |
| 评估 | 训练后取 `best.pt`；读数 = **`metrics/mAP50-95(B)`（val 列，`images/val`）**；判据只在该列上判 |
| 并发 | **每卡单 run（顺序）**；若两卡并行，**同一档的两臂不得跨卡**（与 G1 同纪律） |

**★ 抽样脚本必须满足的三条（写成断言）**

1. **图集不变**：三档的**图像文件名集合完全相同**（== 705 张的那个集合）；
2. **密度单调**：保留下来的**实例总数**满足 `N(d10) < N(d25) < N(d50)`，且与目标比例相差 ≤ 5%；
3. **两臂同集**：同一档的 base 与 strategy **读到同一份标签文件**（同一目录、同一 md5）。

## 4 主分析与判据（冻结）

**主分析（H1）**：每档做十种子配对 t（strategy − base），报均值、SD、t、p、95% CI、种子同号数；
再报**三档之间的符号与幅度**。

**判"标注密度改变符号"（成功）**——三条**同时**成立：

1. **两端异号**：`Δ̄(d10)` 与 `Δ̄(d50)` **异号**；
2. **两端各自可判**：**两端都满足 $|\bar\Delta| \ge 0.30$ pp 且 $p < 0.01$**；
3. **方向一致**：**每一端 ≥ 8/10 种子同号**。

**判"未改变符号"（负结果，同样要报）**：否则按未复制处理，**并如实报出**。

**H2（单调性）**：报三档点估计的**顺序**；**不做趋势检验**（三档、每档十种子，趋势检验的效力不足，
且会把"非单调"这一**要如实报出的形态**平滑掉）。

**多重性**：本件只有**一个域对**进入成功判据 ⇒ 报 BH `q=0.05`（`m = 3` 为三档的两两比较）
**仅作参考**，主判据是上面的三条；**不把 H2 并入家族校正**。

**事前功效**：先验噪声取 **G1 同格实测的 SD**（c1 = 0.166 pp、c2 = 0.211 pp，**两者都已冻结在 G1 判读件里**）。
在最保守的 0.211 pp 与 $n=10$ 下，$\mathrm{MDE} = \gamma(10)\times 0.211 = 0.2099$ pp
**远低于 0.30 pp 条** ⇒ **十种子对本件是充足的**（这一点与 G1 不同：G1 用的是档案中位噪声 0.2744）。
★ **先验在此刻命名、冻结**，不得事后替换。
