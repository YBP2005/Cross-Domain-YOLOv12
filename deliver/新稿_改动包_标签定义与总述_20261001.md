## 0. 这两处为什么是红的（一句话）

现稿用 **`✅CONFIRMED`** 一个标签同时承担两件事：

1. **"这个数我重算过"**（可追溯性）；
2. **"这个数站得住"**（论证强度）。

这两件事**不是一回事**（经验 #26：审计全绿 ≠ 送审就绪）。
`16_draft_tag_paths.py` 逐条落实路径后发现：

* §4.1–§4.5 的数确实**逐位可复算**，但其中 **§4.4 的两个数只在 3 个种子子集上成立**
  （全格 n=10 是 **+1.0958 / +0.1922**，不是 **+1.2747 / −0.0050**）⇒
  "recomputed" 为真，"站得住"**不成立于该子集**；
* §6 的 6 类数**根本不是** "recomputed from the released runs"，
  它们来自**扰动 / 谱 / 划分 / OOM 审计**（证据是本地补材，见 `deliver\审计数字_来源与可复算路径.md`）。

⇒ 标签定义必须**拆开**，总述句必须**去掉"All"**。

## 1. `L4` —— 全局标签定义

**old（逐字）**

> Every number carries a verification tag: **✅CONFIRMED** (recomputed from the released runs in this project) or **⚠PENDING** (A-machine label-axis runs in flight; must be replaced before submission).*

**new**

> Every number carries a verification tag. **✅CONFIRMED** means the number is traceable to a **recorded evidence path** in this project, of one of two kinds: **(a) recomputation from the released per-run tables**, for the §4 and §5 results; or **(b) an archived audit artifact**, for the §6 measurement-chain numbers, which come from perturbation, spectral, split and out-of-memory audits rather than from repeated training. Every ✅CONFIRMED number states **which seed set it uses**; where a cell has ten paired seeds and the reported figure rests on a subset, the subset is named. **⚠PENDING** marks the label-axis campaign, which is not reported here.

**改这一句要连带做的两件事**

1. **§4.4 的两个数必须换成全格值**（+1.27 → **+1.10**、−0.01 → **+0.19**），
   否则定义里"which seed set it uses"立刻自相矛盾。
   逐处 old → new 见 `新稿_改动包_选项1_20260930.md` §1–§3。
2. **§4.3 要写明 n=5**（全稿唯一还用 5 个种子的格）。T3 正在把它补到 n=10
   （见 `01_实验补充_T4_s2ae端点_20261001.md` 的接力链）；补齐后改为"ten paired seeds"。

## 2. `L168` —— 文末状态总述

**old（逐字）**

> *Status: new draft, spine complete. All §4–§6 numbers carry ✅CONFIRMED tags backed by per-seed recomputation recorded in this project; ⚠PENDING marks the label-axis campaign. Nothing in this draft is inherited from the old manuscript's structure.*

**new**

> *Status: new draft, spine complete. Every §4 and §5 number carries a ✅CONFIRMED tag backed by per-seed recomputation from the released run tables, with the seed set named at each tag; the §6 measurement-chain numbers carry ✅CONFIRMED tags backed by archived audit artifacts rather than by repeated training. ⚠PENDING marks the label-axis campaign, which this draft does not report. Nothing in this draft is inherited from the old manuscript's structure.*

**三条改动，逐条对应一个缺陷**

| # | 改动 | 修掉的缺陷 |
|---|---|---|
| 1 | `All §4–§6` → `Every §4 and §5 … ; the §6 … rather than by repeated training` | §6 的数**从来不是** per-seed recomputation（旧句把它们算进去是**事实错误**） |
| 2 | `with the seed set named at each tag` | §4.4 的 3 种子子集问题（旧句的 "All" 让读者以为每处都是全格） |
| 3 | `⚠PENDING marks the label-axis campaign` 保留 | 与 L144（§9 Limitations）一致，无需改 |
