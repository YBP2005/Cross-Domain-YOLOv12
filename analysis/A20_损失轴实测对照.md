# A20 损失轴的**实测对照**（回答"损失轴要不要重跑"）

> 数据 = `base/run_table_canonical.csv`（**2362 行**）。
> 口径：`lr005 − base` 是论文的"增益"；**损失轴**问的是"换损失后这个增益还在不在"。
> ★ 本件只做**可复算**的部分，并把不可算的部分**明确标成缺件**，不估算。

## 一、为什么 `A15` 说"0 格"——那是**管线看不见**，不是数据没有

换损失的 run 名形如 `{族}_{loss}_{轮数}`（如 `dota15_css_100ep`），其 `lr_arm` **为空**：

```
run                          lr_arm   loss    lr0
mende_sns_base100ep_s43n     'base'   sns     0.001
mende_sns_base100ep_s46n     'base'   sns     0.001
mende_sns_base100ep_s47n     'base'   sns     0.001
mende_sns_base100ep_s48n     'base'   sns     0.001
```

`_cells.load()` 的格图**只收 `base` / `lr005` 两臂** ⇒ 这些 run 一个都进不去，
于是"同格两种非空 loss 的格 = 0"。**这个 0 是口径造成的，不是事实。**

★ 归臂是**可判定的**：每个 (配对, 族, 轮数) 下，`base` 臂的 `lr0` 与 `lr005` 臂的 `lr0`
是两枚指纹；换损失 run 的 `lr0` 落在那一边，就属于那一臂。实测：

| 归臂结果 | 条数 |
|---|---|
| 归到 **`base`** 臂（`lr0` 与 base 指纹一致） | **101** |
| 归到 **`lr005`** 臂 | **20** |
| **归不上**（该格没有 shapeiou 两臂可作指纹） | **8** |

归不上的（这些格**没有** shapeiou 两臂，故无法判定换损失跑属于哪一臂）：

* `mafa→mask` / `css` / 100ep —— loss=`css`, lr0=`0.001`
* `mafa→mask` / `pws` / 100ep —— loss=`pws`, lr0=`0.001`
* `mafa→mask` / `pws` / 30ep —— loss=`pws`, lr0=`0.001`
* `mafa→mask` / `sns` / 100ep —— loss=`sns`, lr0=`0.001`
* `mafa→mask` / `sns` / 30ep —— loss=`sns`, lr0=`0.001`
* `smoke_sns→firesmoke` / `smokefs` / 100ep —— loss=`sns`, lr0=`0.001`
* `smoke_sns→firesmoke` / `smokefs` / 100ep —— loss=`sns`, lr0=`0.001`
* `yolo12n→data` / `smoke` / 30ep —— loss=`sns`, lr0=`0.001`

## 三、★★ **对"增益"的损失效应** —— 补实验后**首次可算**

论文的因变量是**增益** `lr005 − base`。"换损失后增益还在不在"需要
**四条腿**同时存在：`shapeiou-base` / `shapeiou-lr005` / `{loss}-base` / `{loss}-lr005`。

实测：换损失的 run 归到 **`lr005` 臂的有 20 条**（第一版是 0 —— 补实验前确实没有这一腿）。

**四条腿齐备的 (格, 损失)：3 个**

  * `mafa→mende` / 族 `mende` / 100ep / 损失 `sns`
  * `mafa→mende20` / 族 `r10` / 100ep / 损失 `sns`
  * `mendein→mende` / 族 `mendein` / 100ep / 损失 `pws`

⇒ ★ **"损失对增益的效应"现在可算** —— 此前本节写"格不存在"，那是**补实验之前**的事实。
⇒ 逐组增益、损失对增益的幅度与 t、符号一致性，见 `analysis\A22_损失对增益_实测.md`（生成器 `scripts\41_A22_loss_on_gain.py`）。

## 四、结论：需不需要重跑？

| 轴 | 现状 | 要重跑吗 |
|---|---|---|
| **base 臂的损失效应** | 可算 **15** 组（过闸门 6 组） | ❌ **不用**（可直接进补充材料） |
| **损失对增益的效应** | **四腿齐备 3 组**（已可算） | ❌ **不用再补**；见 `A22` |

> **最小实验设计（若还要补）**：挑 `n≥3` 的干净格（本件第二节里 n≥3 的那几组），
> 每格补 `{loss}-lr005` 的同样种子 —— 即"换损失跑一遍 lr005 臂"。
> 每格需要 **`n` 个 run**（`n` = 该格已有种子的个数），不是乘积。
