# A17 改名件的时间线与含义

> 数据 `base/run_table_canonical.csv`（2362 行）。
> 改名件 = run 名含 `.incomplete_<日期>_<时刻>` 或前缀 `_PARTIAL_`（前者 50、后者 34）。

## 一、它们对分析有没有贡献？

| 项 | 值 |
|---|---|
| 改名件行数 | **84** |
| **有 test 读数** | **33** |
| 有 val 侧 `best_map50_95` | 84 |

* ⇒ 改名件里 **33 / 84 = 39%** 有 test 读数（2026-10-01 修复生成器查名缺口后）。
* ⇒ 它们**可以**进入 test 侧分析，且**必须**进入 —— 否则就是无理由地丢种子。但**单靠改名件补不出任何格**：见下节"零贡献"的实测口径。
* ⇒ 任何"test 侧 n=10"的说法，要看该格**修好之后**的实际配对数，不能再用"改名件一律没有读数"去推断缺件。见 `A8_缺口复核.md`。

## 三、★ "存档改名"等不等于"被截断"？

| 项 | 数 |
|---|---|
| 改名件 | 84 |
| 其中**跑满名义轮数**的 | **3** |
| 其中**未跑满**的 | 81 |

* **跑满的样例**（证明"改名 ≠ 截断"）：
  * `b2_smoke2sf_base30_s50n.incomplete_20260924_104028`：`30/30` ep，outcome=`archive_snapshot`
  * `b2_smoke2sf_base50_s42n.incomplete_20260923_003114`：`50/50` ep，outcome=`archive_snapshot`
  * `b2_smoke2sf_lr005_30ep_s50n.incomplete_20260924_104028`：`30/30` ep，outcome=`archive_snapshot`

* ⇒ ★★ **存档改名是"来源/治理"分类，不是"完整度"分类**。这正是 `_cells.ok_outcome()` 必须用**实际轮数**（而不是结局标签）来判可用的原因：`archive_snapshot` 里既有跑满的、也有真截断的。
* ⚠ 已知的具体实例：`smoke→sfchd` 30ep 的 s50 **跑满 30/30 但被存档为中断件**。该 run 的 test 读数**本就在 B 侧汇总里**，只是生成器按原始目录名查、查不到；修好之后该格由 9 种子变 **10 种子**（`+3.551 → +3.656`）。对照见 `A5_种子方差.md` §7 与 `D1_s50补测_记录.md`。

> ★ **全域影响（实测，非估计）**：46 个改名件补上了 test 读数，但 145 个 test 侧格里**只有 1 个变化**（就是上面那格）。其余 45 个要么同机已有正常目录供数（36 个），要么只在单臂出现、凑不出配对（9 个）。

## 四、结论

1. 改名件**能**贡献 test 读数（33/84），但**几乎不改变结论**：补入后全域只有 **1** 个格变化。
2. 改名**成批发生**且集中在 09-23 与 09-24 ⇒ 是**运维事件**的痕迹，不是模型行为。
3. **改名 ≠ 截断** ⇒ 任何按 outcome 标签一刀切的筛选都会错；必须按 `epochs_actual` 判（`ok_outcome()` 已如此实现）。
4. **生成器查汇总必须按短名回退** —— 否则改名件的读数会被静默丢弃，并伪装成"这些件没有读数"（本件第一版就是这么写错的）。

> ⚠ 本件是**数据治理**结论，**不进论文正文**；它支撑的是"可复现性声明"与数据字典的纪律。
