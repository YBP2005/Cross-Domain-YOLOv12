## 二、判据①：有没有非 `shapeiou` 的实体

* 非 `shapeiou` 且非空的 run：**129** 个（unique run 129）。
* 构成：`sns` 67、`pws` 42、`css` 18、`jps` 2
* ⇒ **判据①成立**（有实体），所以"A1 说没有非 shapeiou 实体"这个读法**是错的** —— 正确的是"**有实体但没有对照**"，见下。

## 三、★ 判据②：有没有"同一格内含两种非空 loss"

* 格内出现 ≥2 种 loss 值的格：**13** 个。
* **其中"两种都是非空"的格：3 个**。

* ⚠ **判据②成立** ⇒ A1/A2 的否定结论**需要修正**：存在可对照的格。
  * `('mafa→mende', 'mende', 20, 100)` → ['shapeiou', 'sns']
  * `('mendein→mende', 'mendein', 20, 100)` → ['pws', 'shapeiou']
  * `('mafa→mende20', 'r10', None, 100)` → ['shapeiou', 'sns']

### ★★ 3.1 更正：换损失的 run **根本没进格图**

换损失的 run 名形如 `{族}_{loss}_{轮数}`（如 `dota15_css_100ep`），其 `lr_arm` **为空**；
`_cells.load()` 的格图只收 `base` / `lr005` 两臂 ⇒ 这些 run **一个都进不来**。
所以上一节的 0 **不是**"数据里没有损失对照"，而是"管线看不见"。

按 `lr0` 指纹归臂（每格的 `base` 臂与 `lr005` 臂各有自己的 `lr0`）后实测：

| 归臂结果 | 条数 |
|---|---|
| 归到 **`base`** 臂 | **101** |
| 归到 **`lr005`** 臂 | **20** |
| 归不上（该格无 shapeiou 两臂可作指纹） | 8 |

⇒ **base 臂的损失效应是存在的、可算的**（逐组读数见 `analysis\A20_损失轴实测对照.md`）；
⇒ ★ **`lr005` 臂现有 20 条** ⇒ **"损失对增益的效应"已经可算**（补实验前是 0 条；逐组见 `analysis\A22_损失对增益_实测.md`）。
👉 逐条见 `analysis\A20_损失轴实测对照.md`（生成器 `scripts\36_A20_loss_contrast.py`）。

## 四、结论

* ★ **"损失轴在 `_cells` 格图里看不见"这一点仍然成立**：换损失的 run `lr_arm` 为空，
  格图只收 `base`/`lr005` ⇒ 在**那个口径**下"同格两种非空 loss 的格 = 0"。
  > 损失轴的问题**不是"没有非 shapeiou 实体"**（有 129 个 run），
  > 而是**"格图里没有能对照两种损失的格"**。
* ⇒ 论文里若写"我们没有损失轴"，**不能**写成"只有 shapeiou"（那与事实不符，会被 `sns/pws/css` 直接反驳）。
* ★★ **但"不可识别"这个更强的说法，在补实验完成后已经不成立**（2026-10-02）：
  按 `lr0` 指纹把换损失 run 归臂后，**base 臂的损失效应**与**损失对增益的效应**都可算 ——
  逐组数字见 `analysis\A20_损失轴实测对照.md` 与 `analysis\A22_损失对增益_实测.md`。
  ⚠ **本件不重复抄那两个数** —— 抄一次就会漂一次（本脚本曾把 `lr005 臂 = 0` 写死，
  补实验做完后那句就成了假事实）。
  ⇒ 因此**不得**再写"损失轴不可识别"；应写成：
  "损失轴**在格图口径下不可见**，但经 `lr0` 归臂后**可算**，
   且**增益方向在换损失下不变**（幅度未达显著，n=6–7）"。
* ⚠ 那 129 个非 `shapeiou` 的 run **不是废物**：它们支撑上面两件，
  但**不得**在没有对照的格上用来报"损失 A 比损失 B 好"。
