## 三、★ 批次分解：同一配对、不同 `family` 的增益可以差一个量级

本件三代的 run 分属三个 `family`。上面已看到 `family` 与 backbone 混淆，
但**同一个配对内部**换批次同样会动数字 —— 这一节把 `y11_shwd→sfchd` 拆开：

| 族（批次） | 轮数 | `best_map50_95` | `test_map50_95` | n |
|---|---|---|---|---|
| `y11` | 30 | **+1.10** | +1.11 | 10 |
| `y11` | 100 | **−0.005** | +0.010 | 3 |
| `b2` | 100 | **+0.32** | +0.32 | 10 |

⇒ ★ **同一个配对、同一个轮数（100ep），换批次就换数字**：
   `b2` 批次 **+0.32 pp（n=10）** vs `y11` 批次 **−0.005 pp（n=3）**。
   ⇒ 任何把两批**合并**成 "n=10" 的读数，**必须显式声明是跨族合并**
   （`base\数据字典.md` §十.1：跨族合并不能一律禁用，但**必须显式声明**）。
   ⚠ 稿内 §4.4 现写 `+0.19 pp (t = 2.00), ten paired seeds per arm`：
   其 30ep 读数来自 `y11` 批次，而 100ep 的 +0.19 **两个批次都不是**（是合并后的数）
   ⇒ **该处需要声明**。
   ✅ 但**定性结论不变**：无论取哪一批，`yolo11n` 的 30→100ep 都是**从 +1.1 pp 塌到 ≈0**。

## 四、结论

* 逐代（**公共种子 s42–s44**，`best_map50_95` / `test_map50_95`）：
  * `yolo12n`：30ep +0.920 (|t|=5.5) / +0.920 (|t|=6.1)；100ep +0.678 (|t|=5.0) / +0.680 (|t|=5.2)
  * `yolo11n`：30ep +1.275 (|t|=7.0) / +1.287 (|t|=7.1)；100ep -0.005 (|t|=0.1) / +0.010 (|t|=0.2)
  * `yolo26n`：30ep +2.643 (|t|=13.0) / +2.660 (|t|=13.0)；100ep +1.497 (|t|=22.2) / +1.490 (|t|=19.7)

* ⇒ ★★ **没有任何一代的增益显著为负**；`yolo12n` 与 `yolo26n` 在两个轮数上都是**显著正**；
  `yolo11n` 在 **100ep 上塌到与 0 不可区分**（`best` 列 −0.005、`test` 列 +0.010，
  两列符号相反、|t| ≤ 0.2），**这正是 §4.4 已经报告的那个"100 轮上增益几乎消失"的现象**。
* ⇒ 与 `A21`（在 `dota15_20p` 上**只换 backbone**、n=10、两列 10/10 同号）合起来：
  **增益的存在不依赖 backbone 代**（`A21`，干净且 n=10）；
  **增益随预算衰减的幅度依赖 backbone 代**（本件，`yolo11n` 消失、另两代仍在）。

### 边界与保留（必须一并写进论文或不写）

1. **batch 与 backbone 混淆**：三代的 run 分属三个 `family`（批次）⇒
   本件**只报方向与是否与 0 可区分**，**不得**报"哪一代增益更大"。
2. **公共种子仅 s42–s44（n=3）**，远低于论文自己的 **n≥10** 闸门 ⇒ 不得报幅度、不得报显著性。
3. `yolo26n` 只有 **2 个数据集**、`yolo11n` 只有 3 个（见 `A1b`）⇒ 三代可比的**只有这一处目标**。
4. 三代的源权重是**三个分别训练的 `shwd` 预训练**（每代一个）⇒
   本件对比的是"**某代 backbone 连同它自己的预训练**"，不是纯架构。
5. ★ 由本件带出的**独立问题**：同一配对换批次，100ep 增益 +0.325（`b2`, n=10）vs
   −0.005（`y11`, n=3）⇒ **跨族合并必须声明**，否则读出的 "n=10" 是拼出来的。
