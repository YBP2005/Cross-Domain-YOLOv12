## 四、判读

* ≥8 run 的组里，共 **93** 个 run 没有 test 读数 ⇒ 这些 run 在任何 test 侧分析里**都不存在**。
* `interrupted` 全库 **40** 条：它们**没有 test 读数**（eval 未跑到），但**有 val 侧读数** ⇒ 这就是 `_cells.ok_outcome()` 必须独立于"该列是否非空"的原因。
* `archive_snapshot` 全库 **50** 条：`.incomplete_` 存档件**两种都有**（跑满但没写 test 行的、与真中断的）⇒ `ok_outcome()` 用**实际轮数**区分，不能用结局标签一刀切。
* ⇒ **本普查是"数字之外"的元信息**：它不改变任何已算出的数，但决定**每条结论该配多强的措辞**。
