## 五、主分析与判据（**开跑前定**）

| # | 分析 | 判据 |
|---|---|---|
| **H1** | 每格两臂同种子**配对差** Δ（mean / SD / t / p / 同号数） | 逐格 |
| **H2** | ★ **B 层三点走向** Δ(10%) → Δ(30%) → Δ(50%) | 若 30% **与 10% 同号且 \|t\| 显著** ⇒ 反转发生在 **30%→50%**（**边界可定位**） |
| **H3** | ★ **A 层三点走向** | 若三点**同号** ⇒ "反转**限于低域差层**"从单点升为**三点支撑** |
| **H4** | **预算—增益斜率** `(Δ50−Δ10)/Δbudget` 的配对 t | 两斜率**异号且各自过 MDE** ⇒ 域差层调节符号 |
| **H5** | **每格自己的 MDE**（`γ(n)·σ̂`，γ(10)=0.9947） | 凡报"可分辨"必附该格 MDE |
| **H6** | **两列并列**：新 run 同时记 `test_map50_95` 与 `best_map50_95` | 满足预注册件"必须两列并列" |

**止损规则（事前）**：任一格 `σ̂ > 0.6860`（= 2.5× 档案中位 0.2744）⇒ 该格**注册时即判 underpowered**，**如实报出，不得事后加种子**。
