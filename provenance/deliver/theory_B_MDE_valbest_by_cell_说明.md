## 1. 口径（**照抄既有 `theory_B_MDE_by_cell.csv` 的冻结口径，未改**）

$$\mathrm{MDE}=\gamma(n)\cdot\hat\sigma,\qquad
\gamma(n)=\frac{t_{1-\alpha/2,\,n-1}+t_{1-\beta,\,n-1}}{\sqrt{n}},\qquad
\alpha=0.05,\quad \beta=0.20\ \ (\text{power }1-\beta=0.80).$$

* `delta` = 逐种子配对差 `(lr005 − base) × 100`（pp）的**种子间均值**；
  `sd` = 同组差值的**种子间样本 SD**（分母 `n−1`）；`t` = `delta / (sd/√n)`。
* 判据：`resolvable = |delta| ≥ mde`（与既有表的 `resolvable` 语义完全相同）。
* **格键 = `(pair, family, lb, ep)`**，与既有表一致；`lb` 无解（`r10`/`g*`/`s2hv` 等族）写**空**，
  与既有表的写法一致。
* 纳入条件：`n ≥ 3`；`_pick` 的 `LOSS_PREF`（`shapeiou` 优先）与结局优先级
  （`complete > early_stop_legit > archive_snapshot(跑满) > interrupted(一律弃)`）**沿用 `_cells.py` 原样**。
* ★ **同一实现的证明**：本表用的枚举循环与公式，先**在 `test_map50_95` 上重跑了既有 147 行**：
  `n` 全等、`delta` 偏差 < 5e-4、`sd` 偏差 < 1e-6 ⇒ **147/147 逐位吻合、对不上 0 行**，
  且枚举到的格集合与既有表的 147 个键**完全相同**。故本表与既有表是**同一口径的两个列副本**。

## 5. 算不出的格：**0 个**，及审计过的排除类别

val-best 列上**没有任何 `n ≥ 3` 的格算不出来**。逐类审计如下：

| 排除类别 | 本表结果 | 说明 |
|---|---|---|
| (i) `pair/family/ep/lb` 键**不唯一**（同 `(pair, family, ep)` 有多个 `lb`） | **0 格** | 底座里确有 **19 个** `(pair, family, ep)` 组含多个 `lb`（如 `chv→gdut_hwd/s2hv/30` 有 10/20/30/40/50 五个预算），但这些组的 `lb` **都是显式值**，逐格键仍唯一；`lb=None` 的族**不与显式 `lb` 共存**于同一 `(pair, family, ep)` ⇒ 无因歧义被丢的格。 |
| (ii) 该列**无读数**（`_pick` 返回 `None`） | 0 格 | 这些键在枚举时被跳过；对 val-best 列而言，凡 `n ≥ 3` 的键都有可用读数。 |
| (iii) **结局不可用**（`outcome = interrupted` 等被 `ok_outcome` 丢弃，如 `mask→mende/t2` 的 s49 92/100 截断件） | 0 格 | 这类行被 `_cells._pick` 在**格内**排除（不是整格丢弃），因此格仍可算；这正是 `_cells.ok_outcome` 存在的理由（见其 docstring：test 列天然免疫、val-best 列**必须**显式过滤，否则同一格换列会一边安全一边污染）。 |
| (iv) **配对种子 < 3** | 0 格 | 这类键本就不满足纳入条件，不算“算不出”（其余 5 个新增格的 test 列正是这种情况，但 val-best 列补足了 `n ≥ 3`）。 |

**另有一条覆盖结论**：既有 147 行**没有任何一格**在 val-best 列上变成算不出
（`only_test = 0`）⇒ 两表可**按 `(pair, family, lb, ep)` 直接并表逐行对照**。

## 6. 列说明与并表方法

* **列名与既有表逐字一致**（先读既有表再抄，未自创），顺序也一致：
  `pair, family, lb, ep, n, delta, sd, mde, resolvable, t`（**共 10 列**）。
* `lb` 无解写**空字符串**；`resolvable` 写 `True`/`False`；数值格式 `%.15g`；
  **UTF-8（无 BOM）+ `newline=''` + CRLF**，与既有表逐字节同类。
* **并表主键**：`(pair, family, lb, ep)`（`lb` 空串 = 无预算）。与既有表 `merge` 即可得到
  “同一格的 test / val-best 双列”对照。
