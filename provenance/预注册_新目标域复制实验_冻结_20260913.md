## 1. 假设（冻结）

**H1（主假设）**：在三个**未饱和**的新目标域上（100 轮基线 mAP50-95 < 0.30），20% 预算微调时把峰值学习率从 0.001 提到 0.005（其余全同）会带来**正向**的 mAP50-95 增益，且该增益能被**十种子配对检验**分辨。
- 判"复制成功"：**≥2/3 个域对**满足 {增益 ≥ +0.30 pp、配对 p < 0.01、10 个种子里 ≥8 个同向}，且在三个域对上做 **BH（q = 0.05）** 后仍显著。
- 判"未复制"：否则如实报告为未复制，并在正文把学习率结论收窄为"SFCHD 家族内的观察"。

**H2（调节变量，次级假设）**：增益随目标域的 headroom 变化 —— 在**已饱和**的目标域上（100 轮基线 ≥ 0.30）同样的策略增益应≈0。
- 判读：饱和域增益 |Δ| < 0.15 pp 且配对 p > 0.1 → headroom 调节成立；若饱和域也出现 ≥ +0.30 pp 且 p < 0.01 的正增益 → §8.3 的 headroom 收窄叙事**崩**，须重写。

**不检验**：理论界（C1）、几何读数作为预测器、损失先验与结构模块。

## 4. 主分析与判据（冻结）

- **主分析**：每对做十种子配对 t 检验（策略 − 基线，同种子配对），报告均值、t、p、95% CI、配对效应量；三对同时报 **BH（q = 0.05，m = 3）** 与 Bonferroni（α/3 = 0.0167）。
- **判"复制成功"**：≥2/3 对满足 {均值 ≥ +0.30 pp，p < 0.01，方向一致 ≥8/10}，且 BH 后仍显著。
- **判"未复制"**：否则按未复制处理（见 §1）。
- **H2**：T2 单对五种子的配对 t；判读见 §1。T2 因只有 5 种子，不进入 BH 家族（分开报告）。
- **不做的事**：不因中间结果增减种子；不把 T2 并入 T1 的家族校正；不因未达显著而改判据；所有偏离记入审计轨迹。
