# N.3 的 `args.yaml`：现存的与记录的不一致（2026-10-16 查明）

**背景**：Appendix N.3 原本写，第三个配置的 `args.yaml`（记 **1,801 字节**、md5
`2e77971c8f5244c497a5fe4e286c9cf9`）**不在放行集里**，并给出大小与 digest "以便持有人核验"。
第八轮 **4 家评审**（Deepseek −0.2、GLM-5.3 −0.2、GLM-5.3-Flash −0.1、qwen-flash −0.3）要求放行它。

**查明结果：那个 digest 对应的文件在 A 机与 B 机上都不存在。** 实测：

| 位置 | 字节 | md5 |
|---|---:|---|
| A 机 `runs/r10_p_vistod15_base100_3way_s42n/args.yaml`（**本目录放行的就是这一份**） | **1,791** | `4bc03fa0ce9cd728bc5844a2bf663e7d` |
| A 机 `runs/r10_p_vistod15_base100_3way_s42n_oomfix/args.yaml` | **1,805** | （另一变体） |
| **N.3 记录值** | **1,801** | `2e77971c8f5244c497a5fe4e286c9cf9` |

**结论与处置**

1. 该 run **至少被重新启动过一次**（存在 `_oomfix` 变体），因此 `args.yaml` 被覆盖；N.3 记录的是
   **最初启动时**那一份，而它**已不在磁盘上**（116 行、LF 行尾，故 10 字节的差**不是**行尾造成的，
   是内容差异）。
2. 本目录放行的是**现存**版本（1,791 字节），并在 N.3 里标明它**与记录值不同**；
3. 三个变体的关键训练参数**一致**（`model: visdrone_pretrain.pt`、`data: dota15_20p_3way.yaml`、
   `epochs: 100`、`batch: 32`、`imgsz: 640`、`lr0: 0.001`、`workers: 16`），所以**读数的配置归属不受影响**；
   受影响的是"该文件可被逐字节核验"这一条，现已如实降级。
