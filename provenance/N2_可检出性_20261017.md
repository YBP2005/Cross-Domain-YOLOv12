# N-2：迁移增益在同行常用种子数下的可检出性（2026-10-17）

## 0. 一句话结论

**用我们自己的十配对种子实测值当真值：35 个"真实且可检出"的迁移增益里，有 13 个（37%）在三个配对种子下根本测不出来。**而且被漏掉的不只是小效应 —— **本档案里最大的那个增益（+12.14 pp）同样会被漏掉**，因为它的方差大（SD 4.20）。

## 1. 方法（不含任何新实验）

数据：底座 `base/run_table_canonical.csv`，**种子从 run 名解析**（`_sNN`）—— 底座的 `seed` 列大量为空，按该列配对会静默失败。

- 取 **配对种子数 ≥10** 的格：**42** 个。
- 每格：配对增益均值 g、配对差的标准差 s。
- 检出阈值 `MDE(n) = γ(n)·s`，`γ(3)=3.096454`、`γ(10)=0.994714`。
- 「10 种子可检出」= `|g| > MDE(10)`；「3 种子也可检出」= `|g| > MDE(3)`。

## 2. 结果

| 量 | 值 |
|---|---:|
| 配对种子 ≥10 的格 | **42** |
| 10 种子下可检出 | **35 / 42 = 83%** |
| 其中 3 种子下也可检出 | **22 / 35 = 63%** |
| ★ **3 种子会漏掉的真实增益** | **13 / 35 = 37%** |
| MDE 中位（n=3） | **0.954 pp** |
| MDE 中位（n=10） | 0.307 pp |
| 实测 \|gain\| 中位 | 1.938 pp |

## 3. 可引用的主张

> 在一个冻结的 2,362-run 档案上，把每个格的十配对种子当真值：**35 个可检出的迁移增益中有 37% 无法被三配对种子检出**。中位检出阈值在 n=3 时是 **0.95 pp**、在 n=10 时是 **0.31 pp**，而实测增益幅度的中位是 **1.94 pp**。因此**三种子研究只能分辨增益分布的上半部分**，其余部分会被报告成噪声或符号不稳。

★ 这条主张的新颖性在于它**不是"我们做了很多审计"**，而是**对子领域通行做法的定量否证**，且**完全来自已放行数据，零新实验**。

## 4. 限制（必须随文一起说）

- 本分析把整格的 10 种子均值当真值；它本身仍有抽样误差（10 种子下 MDE 中位 0.31 pp）。
- 「3 种子会漏掉」是按 `MDE(3)` 判定的**期望**结论，未做逐三元子集重采样（重采样会给同样的答案，但更慢）。
- 底座的 `seed` 列不可用，配对依赖 run 名；若 run 名与实际种子不符（档案中存在该现象），配对口径需以存储字段为准。
- 语料与模型覆盖面以档案为准：**yolo12n 占 2,241/2,362**，因此该主张应表述为"在这批检测微调实验上"，不宣称跨架构普遍。

## 5. 复现

`base/run_table_canonical.csv` + 上面的 `γ(n)` 与阈值定义即可复算；种子正则 `_s(\d+)`。
